# SafeSpend — Version 1

This is a working mobile-friendly web app prototype.

## Run it
Open `index.html` in a modern browser. It stores demo data in the browser's localStorage.

For phone-style installation, host the folder on a secure (HTTPS) website. The included manifest lets compatible browsers install it as an app.

## What works
- Current balance
- Add income
- Add bills
- Mark bills paid
- Upcoming-bill calculation
- Projected safe-to-spend amount
- "Can I afford this?" calculator
- Calendar-style combined timeline
- Delete items
- Local browser storage

## Important
This is Version 1 / prototype code, not yet a production financial application. Before selling it, add authentication, a secure database, recurring-item logic, notifications, accessibility testing, privacy policy/terms, payment processing, security review, and proper financial-data handling.
